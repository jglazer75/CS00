# Technology Stack

## Frontend & UI
*   **Next.js 15:** React-based framework for high-performance web applications and server-side rendering.
*   **MUI (Material UI):** Comprehensive UI component library for implementing Google's Material Design system.
*   **Tailwind CSS 4:** Utility-first CSS framework for rapid UI development and consistent styling.
*   **TypeScript:** Strongly typed programming language that builds on JavaScript for enhanced developer productivity and code quality.

## Backend & Services
*   **Supabase:** Backend-as-a-Service providing PostgreSQL database, authentication, and real-time capabilities.
*   **Vercel:** Cloud platform for static site hosting and serverless functions, serving as the primary deployment target.

## Content Management
*   **Remark & Gray-matter:** Toolset for parsing and processing Markdown content and YAML frontmatter.
*   **Content Engine:** Custom logic (`lib/content.ts`) for dynamically rendering Markdown files from the repository.
