# Product Guidelines

## Content & Voice
*   **Module Preservation:** You MUST NOT modify the prose style of any learning module. The language in these modules is authored by academics and is critical to the learning experience; preserve it exactly as provided.
*   **Platform UI Voice:** For all non-module interface elements (buttons, tooltips, navigation, help text), use a **clear and concise** voice. Avoid jargon and focus on being helpful to guide the user to their next objective.

## Visual Identity & UI (Material Design)
*   **MUI Adherence:** Strictly follow **Google Material Design** principles via the MUI library. This ensures a predictable, professional, and accessible user experience.
*   **Accessibility First:** All interface elements MUST comply with **WCAG 2.1 AA** standards. Prioritize high color contrast, keyboard navigability, and full screen-reader support.
*   **Card-Based Structure:** Maintain the card-based layout for content to support "chunking" and reduce cognitive load.

## User Interaction & Feedback
*   **Immediate Feedback:** Provide instant visual confirmation for user actions. For example, use green checkmarks or progress bar updates immediately upon section completion.
*   **Contextual Guidance:** Use helpful UI text to ensure the user always knows what they are doing or should be doing next.

## Role-Based Differentiation (Instructor Mode)
*   **Visual Signaling:** When "Instructor Mode" is active, use a distinct visual indicator in the header (e.g., a specific color shift or persistent label) to ensure clear situational awareness.
*   **Explicit Badging:** Mark every instructor-only content card or element with a clear "Instructor" or "Confidential" badge to distinguish it from student-facing material.
